# このサイトについて

## @description マイクロビット ひらがなエディタについて（非公式プロジェクト）

このサイトは、micro:bit のための、すべてひらがな表記のブロックエディタです。
かんじやカタカナがまだむずかしい子でも、ブロックを読みながらプログラミングできるように、日本語の表示をすべてひらがなに置き換えています。

**このサイトは非公式のプロジェクトです。Microsoft および Micro:bit Educational Foundation とは関係がなく、承認を受けたものではありません。**

このサイトは、オープンソースの Microsoft MakeCode (PXT) をもとに、MIT ライセンスのもとで公開されています。ブロックやプログラムの仕組みは MakeCode と同じです。
